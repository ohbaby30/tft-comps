# 云顶之弈国服阵容与出装排名

国服 TFT S18（自然之力）阵容出装参考页，纯静态单页，可直接离线打开。

## 内容

| 文件 | 说明 |
|---|---|
| `index.html` | 导航页 + 当前版本总览 |
| `patches/18.3.html` | 18.3 版本阵容、完整卡组与 C 位出装 |
| `patches/18.2.html` | 18.2 版本存档（历史快照） |

## 使用

- 顶点开 `index.html` 即可，无需服务器、无需联网（棋子头像已 base64 内嵌）
- 所有棋子羁绊数值与排名均来自公开数据站表格逐字提取，页面底部标注了数据来源与统计时间窗口
- 页面内的分级（T0 / 低估 / 版本答案）为整理者按平均名次与前四率自行划分，非官方分级

## 版本与更新

每个补丁版本一个独立页面，历史版本保留为快照，不做覆盖。

数据为整理时点的第三方站点统计快照，版本更新后需重新抓取。
